- ĐỀ THI YÊU CẦU TUÂN THỦ CODING CONVENTION, QUY TẮC ĐẶT TÊN, CHỮ HOA CHỮ THƯỜNG, CẤU TRÚC PACKAGE, VERSION JDK, MÃ SINH VIÊN

                                   ĐẶC BIỆT CHÚ Y KIỂU DATETIME
                                   FORMAT NHẬP NGÀY THÁNG:

                                              13/12

         <module>... </module>
       <modules>

V. TẠO DATABASE THEO ĐỀ, CHẠY SCRIPT THEO ĐỀ, GENERATE NGƯỢC TABLE THÀNH CLASS!!!
- TÊN DATABASE CÓ NẰM O ĐOẠN ĐẦU TRONG ĐỀ O MỤC MÔ TẢ MỖI SERVICE, 
  TẠO 100 GIỐNG CHỮ HOA THƯỜNG VÀ SHIFT GẠCH
  VÍ DỤ THEO ĐỀ: MSS301_2026_PE
- GÕ LỆNH CREATE DATABASE <TÊN DATABASE THEO ĐỀ>, VÍ DỤ CREATE DATABASE MSS301_2026_PE
- GÕ LỆNH USE <TÊN DB> VÍ DỤ USE MSS301_2026_PE ĐỂ CHUYỂN FOCUS VÀO DB NÀY ĐỂ TẠO TABLE
- MỞ 2 FILE SCRIPT, CHẠY THẰNG 1 TRƯỚC, THẰNG N SAU TRONG TRONG CỬA SỔ GÕ CÂU SQL

- KIỂM TRA TABLE CÓ TỒN TẠI CHƯA:
  SELECT * FROM TABLE-1   <-------------THAM CHIẾU PK THẰNG 1 - -------------+

                                                                         OPENFEIGN
                                                                             |
  SELECT * FROM TABLE-N   TRONG THẰNG N PHẢI CÓ CỘT FK TRỞ THẲNG LÊN THẰNG 1 |
